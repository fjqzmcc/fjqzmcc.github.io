# MergeDoku 官方网站

MergeDoku（物品合并数独）官方网站，托管于 GitHub Pages，域名 [www.mccplay.xyz](https://www.mccplay.xyz)。

## 页面

- `index.html` — 首页（游戏介绍 / 特色 / 玩法）
- `privacy.html` — 隐私政策（中英双语）
- `terms.html` — 服务条款（中英双语）
- `support.html` — 技术支持与联系方式
- `404.html` — 自定义 404

## 说明

- `CNAME` 绑定自定义域名 `www.mccplay.xyz`。
- 应用图标 `app-icon.png` 同时作为 favicon 与社交分享图。
- Google Ads / AdMob 审核所需的隐私政策与联系信息均已就位。
